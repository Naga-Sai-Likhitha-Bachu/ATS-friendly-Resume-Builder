# ATS-friendly-Resume-Builder
An AI-Based ATS-Friendly Resume Builder that generates professional resumes from user-provided details, helping job seekers create structured, ATS-compatible resumes with ease.
AI-Based ATS-Friendly Resume Builder 📄

**📌 About the Project**

The AI-Based ATS-Friendly Resume Builder is a web application designed to help students and job seekers create professional, well-structured resumes. Users can enter their personal information, education, skills, projects, and other details to generate a resume in a clean format.

**🎯 Objectives**
- Simplify the resume creation process.
- Generate professional and structured resumes.
- Organize user information into appropriate resume sections.
- Help users prepare resumes suitable for Applicant Tracking Systems (ATS).

**🛠️ Technologies Used**

- Python
- Flask
- HTML
- CSS
- Jinja2 Templates

**✨ Features**
- User-friendly web interface.
- Personal information collection.
- Education and skills sections.
- Project and experience details.
- Dynamic resume generation.
- ATS-friendly resume structure.

**Installation**
1. Clone the repository:
git clone https://github.com/Naga-Sai-Likhitha-Bachu/ATS-friendly-Resume-Builder.git

2. Navigate to the project:
cd ATS-friendly-Resume-Builder

3. Install Flask:
pip install flask

4. Run the application:
python app/app.py

5. Open http://127.0.0.1:5000 in your browser.
